# 行政學第三章：公共行政的政治環境｜Quiz Battle

> **專為大學行政學課堂報告打造的即時多人答題競賽系統**  
> 功能機制高度類似 Kahoot Classic Mode，支援筆電投影螢幕（主持人）與手機快速掃碼加入（玩家）。

---

## 🌟 核心特色

1. **多人即時連線 (WebSocket)**：
   - 零延遲多人雙向同步，支援全班同學同時連線答題。
   - 玩家若網路短暫中斷或重新整理，系統具備自動 Session 重連機制，恢復分數與狀態。
2. **直覺雙入口架構**：
   - **主持人 (Host)**：在大螢幕或投影機上投影，掌控競賽節奏（產生 6 位數 Game PIN、動態 QR Code、即時玩家清單、開始遊戲、提前結束本題、下一題、頒獎台）。
   - **玩家 (Player)**：手機瀏覽器開啟，輸入 PIN 碼或掃描 QR Code（自動代入 PIN 碼），輸入暱稱即可加入等待室。
3. **經典四色大按鈕與視覺辨識**：
   - A：紅色 ＋ 三角形 ▲
   - B：藍色 ＋ 菱形 ◆
   - C：黃色 ＋ 圓形 ●
   - D：綠色 ＋ 方形 ■
   - 手機版優化超大觸控按鈕，點擊後立即鎖定答案並防重複提交。
4. **競賽計分機制（正確率 ＋ 速度）**：
   - 每題 20 秒倒數計時。
   - 答錯：0 分。
   - 答對公式：`score = round(500 + 500 × remainingTime / 20)`
   - 答越快分數越高（500 ~ 1000 分）。總分相同時，以全場累積作答時間較短者排名在先。
5. **每題即時回饋與排行榜**：
   - 主持人畫面：顯示正確答案、四個選項作答人數長條圖分佈、Top 5 排行榜、神速王 / 連勝等勳章。
   - 玩家手機畫面：即時顯示「✓ 答對了！(+XXX 分)」或「✕ 答錯了」，並顯示個人即時排名與連勝次數。
6. **第 15 題專屬附圖**：
   - 題目：請問電影「國四英雄傳」的男主角（如下圖）是？（提示：北大行政系一位非常帥的教授）
   - 正確答案：C. 黃朝盟。
   - 原始比例顯示使用者指定之人物劇照，不裁切臉部、自動適應電腦與手機。
7. **盛大頒獎台 (Podium) 與音效**：
   - 完成 15 題後揭曉前三名階梯式頒獎台動畫（🥇 冠軍、🥈 亞軍、🥉 季軍）。
   - 支援全螢幕彩色紙花慶祝特效 (Confetti)。
   - 內建純 Web Audio API 合成音效（倒數、時鐘滴答、答對、答錯、頒獎勝利號角），不依賴外部音檔，右上角可隨時靜音切換。

## 🚀 啟動與使用方式

### 1. 啟動伺服器
進入專案目錄，執行以下指令：
```bash
python server.py
```
伺服器將在 `http://0.0.0.0:8000` 啟動，並自動偵測區域網路 IP（例如 `http://192.168.31.72:8000`）。

### 2. 主持人操作（投影到教室大螢幕）
1. 筆電打開瀏覽器造訪：`http://localhost:8000`。
2. 點擊「**我是主持人 / 投影螢幕**」按鈕建立遊戲房間。
3. 系統自動產生 6 位數 Game PIN 以及可供手機掃描的 **QR Code**。
4. **網路模式選擇**（QR Code 上方）：
   - 🌐 **雲端公網（推薦）**：伺服器內建 Cloudflare 安全穿透，同學手機無論使用 4G/5G、跨網、或學校 eduroam / 限制型 Wi-Fi，相機一掃即可秒連！
   - 🏠 **區網 Wi-Fi**：提供區域網路連線（如 `http://192.168.31.72:8000`），適合無外網或離線環境。
   - ✏️ **自訂網址**：支援手動輸入自訂網域或 IP。
5. 全班同學加入後，點擊「**開始遊戲**」。
6. 每題答題完畢後，主持人可觀看作答統計長條圖與 Top 5 排行榜，再按「**下一題 ➜**」推進節奏。
7. 第 15 題結束後，點擊「**查看最終頒獎台 🏆**」進行頒獎與慶祝。

### 3. 同學操作（手機加入競賽）
- **方式一（推薦・相機秒掃）**：直接使用手機相機掃描投影幕上的 **QR Code**，網址會自動帶入 Game PIN，同學只需輸入「暱稱」並點擊「加入遊戲」。
- **方式二（貼上連結加入）**：主持人可點擊 QR Code 下方的「📋 複製」按鈕，將加入連結直接發送至班級 LINE 群組或聊天室，同學點開即可加入。
- **方式三（手動輸入）**：手機瀏覽器輸入投影螢幕顯示之網址，手動輸入 6 位數 Game PIN 與暱稱加入。
